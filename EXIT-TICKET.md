## Exit Ticket
Answer each question individually
1. In one sentence, define inheritance.

Inheritance is a OOP mechanism that allows one class to acquire all methods and variables from another class 


2. What is the purpose of extends?

The keyword "extends" allows a class(subclass) to inherit the methods and attributes from another class(superclass).


3. What is the difference between a superclass and a subclass?

The difference is that a superclass is the main(parent base) which provides the methods and variables while the subclass acquires all those properties when its inherited by the superclass.


4. Give one advantage of inheritance.

Inheritance allows method overriding in which a subclass can modify a method originally from a superclass.
